# Cards Menu for Children of current page

Intention is to use this with the DDR Menu MODULE with Node Selection expression = "CurrentChildren"

Docs
https://docs.dnncommunity.org/content/tutorials/themes/theme-objects/ddrmenu/ddrmenu-reference-guide/index.html

1. Add DDR Menu MODULE to page
2. Module Settings / Menu Settings tab
3. Set Menu style: menus/NavCards
4. Set Node selection expression: CurrentChildren
5. Update/Save
